This section introduces how to plan a program before writing it and the building blocks every programming language shares.

## Design before you code

Describe what a program should do, then sketch how it's organized before typing any code. UT Austin's course uses three diagrams for this:

- **Flowcharts** show the order things happen in, including decisions and loops.
- **Data flow graphs** show where information comes from and where it goes.
- **Call graphs** show which parts of the program use which other parts.

## Building blocks

These concepts appear in nearly every language. The UT Austin chapter teaches them in C, the language used on most microcontrollers:

- How a program file is organized
- Variables and constants
- Operators and the order they're evaluated in
- Conditionals (`if`) and loops
- Functions
- Arrays and pointers
